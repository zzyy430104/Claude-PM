# Claude-PM 总体方案（草案 v0.1）

面向轨道交通供应商、对标 **ISO 22163:2023** 的项目管理与质量协同平台（SaaS + 私有部署）。

## 1. 已确定的决策

| 项 | 决定 |
|---|---|
| 标准范围 | 仅 ISO 22163:2023（重点 8.1.2 投标、8.1.3 项目管理、8.1.4 配置与变更） |
| 目标客户 | 多家企业，30–2000 人，云端与私有部署两种方式 |
| 质量模块 | 项目不符合项 / CAR 放在本产品内 |
| 外部协同 | 客户、供应商暂不登录系统 |
| 技术栈 | Node.js 全栈：Angular + NestJS + PostgreSQL（Prisma）+ Redis，TypeScript |
| 仓库 | 全部在 Claude-PM；`angular-auth-qms` 仅作学习资料，不复用 |

## 2. 标准条款到功能的映射

| 条款 | 功能 | 系统强制规则 |
|---|---|---|
| 8.1.3.1 | 项目阶段、里程碑、阶段评审（Gate）：通过 / 有条件通过（附行动计划）/ 拒绝；项目风险分级；拒绝时升级 | 上一阶段评审的未关闭问题未清，不能通过评审，除非最高管理层授权 |
| 8.1.3.2 | 项目管理计划：组织架构、目标、职责权限、各职能计划、按阶段交付物、联合体接口 | — |
| 8.1.3.3 | 范围管理：WBS、工作包、工作包负责人、工作包核验 | 范围变更须经批准 |
| 8.1.3.4 | 进度：活动依赖、工期、甘特图、关键路径 | 客户交期变更须先向客户提出变更申请 |
| 8.1.3.5 | 成本：成本科目结构、实际成本、完工估算（EAC） | 预算增加须经授权 |
| 8.1.3.6 | 项目质量计划、检验与控制活动、项目不符合项 / CAR | — |
| 8.1.3.7 | 项目角色、任命书、能力要求、培训 | — |
| 8.1.3.8 | 沟通计划、会议纪要 | — |
| 8.1.3.9 | 风险与机会登记册（含成本收益分析） | — |
| 8.1.3.10 | 外部供方交付物跟踪（对接 8.4） | — |
| 8.1.3.11 | 定期项目评审：计划与实际、预测、风险、遗留行动项，结果上报 | — |
| 8.1.4.2 | 变更控制：申请 → 原因分析 → 影响分析 → CCB 审批 → 实施 → 有效性验证 | 审批前不得实施，全程可追溯 |
| 8.1.4.1 | 配置管理：PBS、配置项、基线（设计态 / 制造态 / 维护态） | — |
| 8.1.2 | 投标管理：需求、风险、成本估算、报价审批 | — |
| 8.1.3.1.3 / 7.5 | 文档管理：标准目录、版本、评审记录保留 | — |
| 8.1.3.1.2 | 经验教训库（项目关闭时） | — |

通用要求：全量审计日志；重要记录只能作废不能删除；中英文双语；可导出审核证据包。

## 3. 角色

- 平台层：平台管理员（管理租户）。
- 企业层：企业管理员、最高管理层、职能经理（质量 / 设计 / 采购 / 生产 等）。
- 项目层：项目经理、项目质量经理、工作包负责人、评审参与者、只读成员。

## 4. 技术架构

- monorepo：`apps/web`（Angular + Angular Material）、`apps/api`（NestJS）、`packages/shared`（共享类型）。
- 多租户：所有业务表带 `tenant_id`，在数据访问层强制过滤。
- 认证：JWT + 刷新令牌，预留 OIDC / LDAP。
- 文件存储：S3 兼容（MinIO），私有部署与云端通用。
- 异步任务：Redis 队列（通知、导出）。
- 部署：Docker Compose 私有部署包；云端使用同一套镜像。
- 每个租户可配置：阶段模板、Gate 清单、项目分级规则、审批权限。

## 5. 分批交付

| 批次 | 内容 |
|---|---|
| A 地基 | monorepo、多租户、登录、角色权限、审计日志、Docker |
| B 计划层 | 项目与分级、阶段模板、项目管理计划、WBS、任务、甘特图与关键路径 |
| C 控制层 | Gate 评审、项目评审、变更控制、风险 / 机会登记册 |
| D 质量与成本 | 项目质量计划、不符合项 / CAR、成本科目与 EAC |
| E 支撑层 | 文档管理、经验教训库、配置管理、投标管理 |
| F 收尾 | 通知、报表仪表盘、审核证据包、中英文双语、私有部署包 |

建议批次 C 完成后先给真实企业试用，再决定后续投入。

## 6. 风险与待确认

- 范围较大，需要分批验收。
- 多租户隔离和权限需要人工做安全审查。
- 待确认：批次优先级（是否提前 CAR）；集成（企业微信 / 钉钉 / 飞书 / SSO）的时间点。
